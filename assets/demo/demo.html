WeavePage 织页

所见即所得的本地网页编辑器 — 像 Dreamweaver 一样「织」网页,但更轻、更简单。

所见即所得 多标签页 源码视图

打开任意 HTML 文件,立即呈现完整的 CSS 样式与 JS 动态效果。编辑界面就是最终效果,保存即发布。

功能一览

功能说明
Word 风格功能区字体 / 字号 / 颜色 / 高亮 / 对齐 / 列表 / 表格 / 图片 / 链接
网页预览完整 CSS / JS 动态效果,可直接编辑
源码视图查看编辑完整页面代码(head、CSS、JS)
块级源码编辑右键任意块,侧边栏直接编辑该块 HTML
多标签页同时打开 HTML / CSS / JS 文件

使用步骤

  1. 下载安装包,双击安装(自动安装 WebView2 运行时)
  2. 文件 → 打开,选择 HTML 文件
  3. 直接编辑,所见即所得
  4. Ctrl+S 保存
数据是基础、货盘是核心、人群是关键 — WeavePage 让网页编辑回到「所见即所得」本身。
