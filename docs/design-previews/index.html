Document Designs for WeavePage v2.1.0 — 8 个风格 + 1 个默认按钮

使用说明:点击下方任一卡片,在浏览器中打开对应的预览 HTML,即可看到该风格在真实样例文档(标题/正文/引用/代码/表格/列表等)上的渲染效果。 每个预览页都嵌入了该设计的 完整 CSS(与 spec §6 一致),用户可浏览器全屏查看或截图作为设计参考。

1

经典学术

Classic Academic

白底 + 思源宋体 + 严谨排版。适合论文、文档、教材。
2

现代简约

Modern Minimalist

白底 + Inter 无衬线 + 大行距。Notion 风,适合产品文档、技术博客。
3

文艺书卷

Literary Scroll

米黄/宣纸 + 衬线 + 温暖手感。得到/中信风,适合散文、随笔。
4

科技感

Tech Dark

深蓝/黑底 + 等宽字体 + 霓虹点缀。GitHub Dark 风,适合技术文档。
5

商务正式

Business Formal

浅蓝灰底 + 深蓝标题 + 稳重大气。麦肯锡/领英风,适合企业宣传。
6

柔雅

Soft Elegant

柔粉/裸色 + 衬线 + 圆角 + 轻奢感。适合生活方式、女性向内容。
7

薄荷清新

Mint Fresh

薄荷绿底 + 无衬线 + 清新自然。适合个人博客、手账、生活方式。
8

复古印刷

Vintage Print

牛皮纸底 + 衬线 + 做旧质感。适合怀旧、上世纪主题内容。
关于"默认"按钮:不渲染预览 HTML。当用户选择"默认"时,WeavePage 移除文档中所有 <style data-weavepage-design> 标签,文档回到浏览器默认渲染(Times New Roman + 默认行距)。 用户打开预览页看到的是浏览器默认效果,未注入任何设计样式。
